Play on Android

Method 1: Firefly APK (Recommended)

  1. Download and install the Firefly APK.
    2. Download Firefly.apk (v5.05)
  2. Open the Firefly app after installing.
  3. Click on "Start".
  4. The app will automatically open Growtopia and connect you to the Firefly Private Server.

Method 2: Virtual Hosts

  1. Download and install the Virtual Hosts app.
    2. Download virtual_host.apk
  2. Download the hosts file.
    3. Download firefly.txt
  3. Open Virtual Hosts and click on "Select/Reselect hosts file".
  4. Select the `firefly.txt` file you just downloaded.
  5. Click the large toggle switch to turn it on (it should turn green).
  6. Open Growtopia and connect!

Method 3: PowerTunnel

  1. Download and install the PowerTunnel App from the Play Store.
  2. In the app, add this URL to the "Hosts File URL" field.
  3. Change the "Hosts file update period" to "On start".
  4. Go back to the main menu and click "Connect".
  5. Once connected, open Growtopia and log in.
