Android Guide

Android gives you three workable routes into Firefly.

You can join through Virtual Hosts, through PowerTunnel, or through the direct Firefly APK. The APK route is the quickest, while Virtual Hosts and PowerTunnel let you keep the normal Growtopia app.

Fastest route: Firefly APK No root required Virtual Hosts and PowerTunnel supported

Before you start

  • Use Firefly APK if you want the quickest route and do not want to configure a routing app.
  • Use Virtual Hosts or PowerTunnel if you want to stay on the regular Growtopia app.
  • Firefly.txt is the hosts file used by Virtual Hosts, while PowerTunnel uses the Firefly hosts URL directly.

Switch method

Recommended: direct Firefly.apk

This is the fastest Android route. Download Firefly APK, open it, press start, and it will launch Growtopia already pointed at Firefly Private Server.

Download Firefly.apk

Download Firefly APK here. This is the direct package route and does not require Virtual Hosts or PowerTunnel.

Download Firefly.apk

Install and open the APK

Install the downloaded APK. If Android asks, allow installs from your browser or file manager first, then open Firefly APK.

Click start

Press Start inside the Firefly APK. It will automatically open Growtopia and automatically connect to Firefly Private Server.

Note: PowerTunnel and Virtual Hosts are not required for this method.

Virtual Hosts route

Use this route if you want to keep the regular Growtopia app and load Firefly through the downloaded hosts file.

Download and install Virtual Hosts

Download the Virtual Hosts app from the Firefly link below, then install it on your phone.

Download Virtual Hosts

Download the hosts file

Download the prepared Firefly hosts file, then keep it in the folder where your browser saves downloads.

103.150.227.49 www.growtopia1.com 103.150.227.49 www.growtopia2.com
Download hosts file

Load firefly.txt in Virtual Hosts

Open Virtual Hosts, press Select/Reselect hosts file, then choose the downloaded firefly.txt file from your Downloads folder.

Enable it and connect

Click the big white checkbox until it turns green, then open Growtopia and connect.

Note: Turn Virtual Hosts off again whenever you want to connect back to the official server flow.

PowerTunnel route

PowerTunnel uses the Firefly hosts URL directly, so you do not need to import firefly.txt into it.

Download and install PowerTunnel

Download the PowerTunnel app, then install it on your phone.

Download PowerTunnel setup

Add the Firefly hosts file URL

In PowerTunnel, set the Hosts File URL to the exact address below.

https://hotaru.id/download/firefly/

Change the update period

Make sure the Hosts file update period is set to On start.

Connect and open Growtopia

Go back to the main menu, click Connect, wait for PowerTunnel to connect, then open Growtopia and log in.

Note: Stop PowerTunnel whenever you want to move back to the official Growtopia server.
