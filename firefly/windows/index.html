Windows Guide

Windows can connect through Firefly Helper or the manual hosts route.

The easiest route is Firefly Helper: run it as Administrator, let it copy the Firefly lines for you, open the hosts file automatically, save, and then launch Growtopia. If you want to do it fully by hand, the manual hosts method is still below.

Recommended: Firefly Helper Works with standard Growtopia Manual fallback included

Before you start

  • Firefly Helper already requests Administrator access for you when Windows needs it.
  • Both Firefly lines still need to stay together, whether you use the helper or the manual route.
  • Remove or comment the lines later if you want to return to the official server.

Switch method

Recommended: Firefly Helper

Firefly Helper is the easier Windows route. It asks for admin permission, copies the Firefly lines to your clipboard, opens the hosts file in Notepad, and flushes DNS after you save.

Download Firefly Helper

Download the helper script below, then run it. If Windows asks, allow it to run as Administrator.

Download Firefly Helper

Choose your language

The helper lets players choose English or Bahasa Indonesia before it continues.

Paste the Firefly lines when Notepad opens

The helper copies the two Firefly lines to your clipboard, opens the hosts file automatically, and tells you to scroll to the bottom and press Ctrl + V.

103.150.227.49 www.growtopia1.com 103.150.227.49 www.growtopia2.com

Save and let the helper finish

Save the hosts file in Notepad, close it, and the helper will flush DNS automatically. After that, open Growtopia and connect.

Note: Firefly Helper does not skip the hosts edit. It just makes the Windows route easier by handling admin access, clipboard copy, and DNS flush for the player.

Manual Windows hosts-file route

Use this if you prefer to edit the hosts file yourself without the helper script.

Open the hosts file path

Press Win + R, paste the path below, and open it with Notepad or another editor.

C:\Windows\System32\drivers\etc\hosts

Add the Firefly lines

Go to the bottom of the hosts file and paste both mappings exactly as shown here so the client resolves to Firefly. If you prefer, download the prepared text file first and copy from there.

103.150.227.49 www.growtopia1.com 103.150.227.49 www.growtopia2.com
Download hosts file

Save with Administrator access if needed

If Windows refuses the save, reopen your editor as Administrator, apply the same change again, and then save it with elevated permission.

Launch Growtopia

Open the game normally. If the file was saved correctly, Growtopia should now connect to Firefly instead of the official server.

Note: To go back to the official server, remove the Firefly lines or add # in front of them so they no longer apply.

Quick checks

  • If you want the easiest route, use Firefly Helper first and only switch to manual if you prefer editing the file yourself.
  • If the game still points to the old server, check whether there are duplicate growtopia entries elsewhere in the hosts file.
  • If Notepad opens read-only, restart it as Administrator first.
  • Use the platform switcher above if you also play on macOS, iOS, or Android.
