Windows

Join Firefly on Windows.

Use Firefly Helper for the easiest setup. It opens the Windows hosts file for you, copies the Firefly lines, and refreshes DNS after you save.

Recommended: Helper Manual method included Needs Administrator access

You need

  • Growtopia installed on Windows.
  • Administrator permission to edit the hosts file.
  • Both Firefly host lines saved together.

Choose method

Recommended method

Best for most Windows players.

Download Firefly Helper

Run it as Administrator when Windows asks.

Download Firefly Helper

Let it open the hosts file

The helper copies the Firefly lines to your clipboard and opens Notepad.

Paste this at the bottom

103.150.227.49 www.growtopia1.com 103.150.227.49 www.growtopia2.com

Save, close, and play

Save the file, close Notepad, let the helper finish, then open Growtopia.

Manual hosts method

Use this if you do not want to run the helper.

Open Notepad as Administrator

Search Notepad, right-click it, then choose Run as administrator.

Open the hosts file

In Notepad, open this file path:

C:\Windows\System32\drivers\etc\hosts

Add the Firefly lines

103.150.227.49 www.growtopia1.com 103.150.227.49 www.growtopia2.com

Save and launch

Save the hosts file, close Notepad, then open Growtopia.

Switch back: remove the two Firefly lines, save, then restart Growtopia.
