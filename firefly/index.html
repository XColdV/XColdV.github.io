How to join Firefly

Pick your device below and follow the steps. Takes about 2 minutes.

Pick a method

FireflyConnector Recommended

The official connector app. Easiest way in.

Download FireflyConnector

Download FireflyConnector

Install it

If Android blocks the install, tap "Install anyway" or allow installs from your browser in Settings.

Open it and tap Start

FireflyConnector will open Growtopia and route it to Firefly automatically.

To switch back: just open the normal Growtopia app instead of using FireflyConnector.

FFPS.apk

A Growtopia APK already pointed at Firefly. Install and play.

Download FFPS.apk

Download FFPS.apk

Install it

Allow installs from unknown sources if Android asks. It's safe.

Open it and play

It works just like normal Growtopia but already connects to Firefly.

To switch back: open the original Growtopia app instead.

Legacy methods Not supported

These still technically work but we no longer support them. Use FireflyConnector or FFPS.apk above instead.

iOS — Surge 5

You need Surge 5 from the App Store. Load the Firefly profile and you're done.

Install Surge 5

Get it from the App Store. It costs money, but it's the cleanest method on iOS right now.

Download the Firefly profile

In Surge, go to Profiles → Download from URL and enter:

https://ffps.fun/download/ios

Select and enable the profile

Pick the downloaded Firefly profile and enable it. Accept the VPN prompt if iOS asks.

Open Growtopia

Launch Growtopia normally. It'll connect to Firefly.

To switch back: turn off the Surge profile in the app, then restart Growtopia.

Profile URL

https://ffps.fun/download/ios

Not working?

  • Make sure the profile is active, not just downloaded.
  • Turn Surge off and back on.
  • Fully close and reopen Growtopia.
Pick a method

Firefly Helper Easiest

Download and run it. The Helper adds the Firefly lines to your hosts file automatically and refreshes DNS. Nothing to edit manually.

Download Firefly Helper

Download Firefly Helper

Run as Administrator

Right-click the file → "Run as administrator". It needs admin to edit the hosts file.

Pick a language and press any key

The Helper writes the Firefly lines and flushes DNS automatically. No manual editing needed.

Open Growtopia

Done. Launch the game and you're in.

To remove later: open C:\Windows\System32\drivers\etc\hosts with Notepad++ as admin and delete the two Firefly lines.

Manual — Notepad++

Use this if you prefer doing it yourself or the Helper doesn't work.

Install Notepad++

Get it from notepad-plus-plus.org. Regular Notepad can't save system files properly.

Open the hosts file with Notepad++

Right-click Notepad++ → "Run as administrator", then open:

C:\Windows\System32\drivers\etc\hosts

Add these two lines at the very bottom

103.150.227.49 www.growtopia1.com 103.150.227.49 www.growtopia2.com

Save and play

Save (Ctrl+S), close Notepad++, then open Growtopia.

Tip: make sure there are no other growtopia1.com or growtopia2.com lines already in the file before adding these.

macOS — edit your hosts file

Add two lines to /etc/hosts, flush DNS, and you're in.

Open Terminal

Cmd+Space → search "Terminal" → open it.

Open the hosts file

sudo nano /etc/hosts

Enter your Mac password when asked. It won't show as you type — that's normal.

Add these two lines at the bottom

103.150.227.49 www.growtopia1.com 103.150.227.49 www.growtopia2.com

Use arrow keys to move to the end of the file, then paste.

Save and exit nano

Press Ctrl+O to save, then Ctrl+X to exit.

Flush DNS

sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder

Open Growtopia

Launch the game. Should connect to Firefly.

To switch back: remove the Firefly lines from /etc/hosts, flush DNS again, restart Growtopia.

Host lines

103.150.227.49 www.growtopia1.com 103.150.227.49 www.growtopia2.com

DNS flush command

sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder

Not working?

  • Confirm both lines are in /etc/hosts.
  • Run the DNS flush again.
  • Fully close and reopen Growtopia.
