Join Firefly on macOS.

macOS uses the hosts file. Add two Firefly lines, save the file, flush DNS, then open Growtopia.

macOS hosts method

Follow these steps in order.

Open the hosts file

Use Finder's Go to Folder, or open it from Terminal.

/etc/hosts

Paste the Firefly lines

Add these at the bottom of the file:

103.150.227.49 www.growtopia1.com 103.150.227.49 www.growtopia2.com

Save the file

macOS may ask for your password. That is normal because this is a system file.

Flush DNS

Run this in Terminal:

sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder

Open Growtopia

Start the game normally. It should now route to Firefly.

Switch back: remove the Firefly lines, save, flush DNS again, then restart Growtopia.

If it does not work

  • Confirm both lines are still in /etc/hosts.
  • Run the DNS command again.
  • Fully close and reopen Growtopia.
