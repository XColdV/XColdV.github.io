iOS Guide

On iOS, Firefly is easiest through one clean Surge profile.

iOS does not expose the same host-editing flow as Android or desktop, so the most reliable route is a small Surge profile that maps both Growtopia domains to the Firefly IP.

Recommended app: Surge Uses local VPN profile Fast switch back to official

Before you start

  • Install Surge from the App Store before starting the setup.
  • iOS will ask for VPN configuration permission the first time you enable the profile.
  • Disable the profile later if you want Growtopia to resolve back to the official server.

Surge profile setup

Surge keeps the iOS setup small and readable: make one profile, paste one host block, enable it, then open Growtopia.

Install Surge

Download Surge from the App Store. If you already use another iOS routing tool, the same Firefly host mapping can usually be adapted there too.

Create a Firefly profile

Create a new profile and name it something clear, such as Firefly Server, so it is easy to enable and disable later.

Paste the host mapping into the profile

Add the block below under the Host section so both Growtopia domains resolve to the Firefly IP instead of the official server.

[Host] www.growtopia1.com = 103.150.227.49 www.growtopia2.com = 103.150.227.49

Enable the profile and launch Growtopia

Turn the profile on, accept the VPN configuration prompt if iOS asks, and then open Growtopia. If the block was entered correctly, the game should resolve to Firefly.

Note: Surge is a paid tool, but it remains the cleanest iOS recommendation here because the setup is simple and easy to reverse when needed.

Copy block

[Host] www.growtopia1.com = 103.150.227.49 www.growtopia2.com = 103.150.227.49

What matters on iOS

  • Do not split the two domain lines. Both need to stay in the same profile.
  • Stop the Surge profile whenever you want the official Growtopia route back.
  • If Growtopia still resolves incorrectly, disable and re-enable the profile before trying again.
