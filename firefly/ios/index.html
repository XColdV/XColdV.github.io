iOS

Join Firefly on iOS.

iOS needs a routing profile. The cleanest method here is Surge: create one Firefly profile, paste the Host block, turn it on, then open Growtopia.

Recommended: Surge Local VPN profile Easy to turn off

You need

  • Surge installed from the App Store.
  • Permission to add a VPN configuration.
  • The Firefly Host block below.

Surge method

Keep the two Host lines together. That is the important part.

Install Surge

Open the App Store, install Surge, then open it.

Create a new profile

Name it Firefly so you can find it later.

Paste this Host block

[Host] www.growtopia1.com = 103.150.227.49 www.growtopia2.com = 103.150.227.49

Enable the profile

Allow the VPN configuration prompt if iOS asks.

Open Growtopia

Launch the game normally and connect.

Switch back: turn off the Surge profile, then restart Growtopia.

Host block

[Host] www.growtopia1.com = 103.150.227.49 www.growtopia2.com = 103.150.227.49

If it does not work

  • Check that both Host lines are in the same profile.
  • Turn the profile off and on again.
  • Fully close and reopen Growtopia.
