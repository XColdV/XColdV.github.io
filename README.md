# Firefly Private Server Website

A modern gaming server website with a clean white and green color scheme inspired by Growtopia Private Server aesthetics.

## 🎨 Design Features

### Color Scheme
- **Primary Green**: `#2ecc71` - Main brand color
- **Accent Green**: `#00ff88` - Highlights and interactive elements
- **White Background**: `#ffffff` - Clean, modern base
- **Text Colors**: Dark grays for excellent readability

### Visual Elements
- Smooth gradient backgrounds with animated mesh effects
- Glass-morphism cards with hover animations
- Glowing shadows on interactive elements
- Professional transitions and micro-interactions
- Parallax scrolling effects
