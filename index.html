Server Overview

A GTPS with banners at the center.

Firefly is not a plain copy of Growtopia. Its main pull is banner progression, pity, custom utility items, and regular content updates.

What Firefly is

Firefly is a GTPS made by Hotaru Interactive, formerly Firefly Team. It uses banner events as a core system, with pity to make long-term pulls feel less random.

Progression also comes from custom items, events, dungeons, fishing, and Offers to Odyssey, where normal activity can turn into useful rewards.

Main Loop Banners and pity

Pull, save pity, chase rewards, and build around event items.

Side Content Dungeons, fishing, tickets

More ways to play than only farming or waiting for the next banner.

Custom Items Not only cosmetic

Some items help with gems, XP, or other progression value.

Ranks

Supporter ranks with daily value and utility.

Firefly ranks focus on Lunarium, commands, banner perks, and quality-of-life upgrades.

Firefly Special Pass

15K IDR

Entry supporter package with daily rewards and basic utility commands.

  • 1 Firefly Lock and 25 Platinum Locks
  • 320 Lunarium per day
  • /info, /vsb, /sdb, /ssb
  • All VIP benefits

Guardian

30K IDR

A stronger daily package with banner perks and more server utility.

  • 640 Lunarium daily
  • 1 Firefly Lock and 75 Platinum Locks daily
  • Legacy Banner Choice on first login
  • [GUARDIAN] prefix and upgraded /ssb

Vanguard

70K IDR

The highest public player package, built for daily value and banner chasing.

  • 1200 Lunarium daily
  • 1 Firefly Lock and 100 Platinum Locks daily
  • Veteran Banner Choice
  • Free /sdb and stronger utility perks
